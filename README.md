## About

**Square solver** provides a wide range of tools to solve and sketch polinomials with power less than 3.
From this place we will consider eqautions only with power less than 3 :)

* Solving - a program can solve any given equations and automatically check roots 
* Testing - if you want to test this program. It can be: manual (input from console), file (input from .txt file), unit (testing on ready tests)
* Graphical - a program can sketch any function. Scaling is provided :)
